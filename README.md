# COP31 poster, English version

Live page: https://geohusrev.github.io/cop31/

This URL is printed as a QR code on the Turkish poster presented at COP31 (Antalya, 9-20 November 2026). The printed code cannot be changed.

**Do not** rename this repository, rename the GeoHusrev account, make this repository private, delete it, or move/rename `index.html`, `poster.jpg`, `poster-full.jpg` or `poster.pdf`. Any of these breaks the printed QR code.

Files: `index.html` (static page, no scripts, no external resources, no cookies), `poster.jpg` (3000 px display copy), `poster-full.jpg` (8268x11811 px), `poster.pdf` (original print PDF, 70x100 cm).
